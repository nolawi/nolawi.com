🧭 Switchback

Pick a stop on a bike-to-cabin trail and see how a control can show its state with shape, words, and color.

Open Switchback on its own

<main>
<h1>Switchback</h1>
<p>Pick a stop on an illustrated trail. Try the arrow keys once a stop has focus. Each choice gives you an icon, a name, and a clear selected state.</p>
<fieldset>
<legend>Choose a trail stop</legend>
<div class="routes">
<label><input type="radio" name="stop" value="0" checked> Trailhead</label>
<label><input type="radio" name="stop" value="1"> River bend</label>
<label><input type="radio" name="stop" value="2"> Lookout</label>
</div>
</fieldset>
<ol class="trail" aria-label="Trail map">
<li aria-current="step"><span aria-hidden="true">🚲</span>Trailhead</li>

<li><span aria-hidden="true">🏡</span>Lookout</li>
</ol>
<output id="trail-note">Trailhead. Grab your bike and follow the gravel road.</output>

const stops = Array.from(document.querySelectorAll('.trail li'));
const note = document.querySelector('#trail-note');
const notes = [
  'Trailhead. Grab your bike and follow the gravel road.',
  'River bend. Pull the kayak up on the bank and take a break.',
  'Lookout. Park by the cabin and enjoy the view.'
];
document.querySelector('fieldset').addEventListener('change', ({ target }) => {
  if (target.name !== 'stop') return;
  const selected = Number(target.value);
  stops.forEach((stop, index) => {
    if (index === selected) stop.setAttribute('aria-current', 'step');
    else stop.removeAttribute('aria-current');
  });
  note.value = notes[selected];
});
